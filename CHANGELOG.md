# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-16

### Added
- **Stitched 3D Realms**: India Developer Desk (Bengaluru) and US Dining Table (Austin) connected via Argon Portal Bridge
- **10 Semantic Props**: Coffee Mug, Mechanical Keyboard, 4K Monitor, Tech Books, Gaming Mouse (India) + Cereal Box, Fruit Bowl, Milk Carton, Chrome Toaster, Napkin Stack (US)
- **Material-Based Ballistics**: Ceramic/Metal = Hard Cover with ricochet sparks, Cardboard/Paper = Destructible with staged deformation
- **Hybrid Combat System**: Tactical Soldier and RC Combat Car with morph toggle [V]
- **Weapon System**: Plasma rounds (auto-fire) and Breach Grenades (area damage, 3.5s cooldown)
- **Argon Vision**: Semantic bounding box overlays on all props [T]
- **Dual Scan & Stitch**: 4-stage arena reconstruction with scan line animation [R]
- **WebRTC P2P Multiplayer**: Auto-pairing via BroadcastChannel for same-browser tabs
- **Cross-Device WebRTC**: Manual Base64 SDP Offer/Answer exchange
- **AI Sparring Bot**: Tactical opponent with cover-seeking, flanking, and mode morphing
- **3 Camera Views**: Chase, Overhead Tactical, Bridge Action [K]
- **Synthesized Audio**: Web Audio API sound effects (no external files)
- **On-Screen Controls**: Touch-friendly D-Pad and action buttons
- **Production Backend**: Spring Boot 3.3 with WebSocket signaling and REST scan API
- **Infrastructure**: HAProxy load balancer config, Docker multi-stage build, docker-compose
- **CI/CD**: GitHub Actions pipeline with Maven build and Docker image
- **Architecture Suite**: In-game modal with production source code viewer and copy feature
- **Full Documentation**: README, Contributing guide, Architecture doc, Security policy
